# P1: Project Folder and Terminal Navigation

## Aim
To understand how to create project folders and navigate through them using terminal commands.

## Commands Practised

| Command | Purpose |
|---|---|
| `pwd` | Displays the current working directory |
| `ls` | Lists files and folders |
| `cd P1` | Enters the P1 folder |
| `cd ..` | Moves one directory backwards |
| `cd ../..` | Moves two directories backwards |
| `mkdir practice` | Creates a new folder named practice |
| `rmdir practice` | Removes an empty folder named practice |

## Procedure
1. Opened the project repository in VS Code.
2. Created the Module1 and P1 folders.
3. Used `pwd` to check the current directory.
4. Used `ls` to list the available files and folders.
5. Used `cd` to navigate between directories.
6. Used `mkdir` to create a practice folder.
7. Used `rmdir` to remove the empty practice folder.

## Result
Successfully created the project folder structure and practised basic terminal navigation commands.
