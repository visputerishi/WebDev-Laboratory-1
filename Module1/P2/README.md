# P2: Portfolio Repository and Initial Commit

## Aim
To create a Git repository for the portfolio project and make its first commit.

## Repository
- Local project folder: `WebDev-Laboratory-1`
- GitHub repository: `https://github.com/visputerishi/WebDev-Laboratory-1`
- Default branch: `main`

## Procedure
1. Opened the project folder in VS Code.
2. Initialized the project as a Git repository.
3. Connected the local repository to its GitHub remote.
4. Created the initial commit on the `main` branch.

## Verification
The repository has an `Initial commit` on `main`, and the `origin` remote points to the GitHub repository above.

## Result
The portfolio project repository is set up and ready for future work.
