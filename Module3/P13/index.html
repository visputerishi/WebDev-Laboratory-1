P13 · Layout systems

Flexbox or Grid.

Both are useful. Choose based on whether you are arranging items in one dimension or two.

Flexbox one dimension

Items flow in a row and wrap as space allows.

Grid two dimensions

Rows and columns work together to create a shared structure.

01

Plan

Start with the content.

02

Arrange on one axis.

03

Allow items to wrap.

In practice: use Grid for the overall project-card layout and Flexbox inside a card or header when its content follows one direction.
