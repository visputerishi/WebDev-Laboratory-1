# P13: Choosing Between Flexbox and Grid

## Aim
Compare Flexbox and Grid and choose a layout method based on the shape of the content.

## Rule of thumb
- Use Flexbox when arranging items along one primary axis, such as a navigation row or footer.
- Use Grid when the layout needs rows and columns together, such as project cards or a newspaper page.
- Combine them when a two-dimensional page contains one-dimensional components.

## Demonstration
Open `index.html` to see the same collection of cards arranged first with Flexbox and then with Grid. Resize the page to compare how each layout responds.
