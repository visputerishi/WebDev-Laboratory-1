# P11: Newspaper-Style Three-Column Layout

## Aim
Build an editorial page with a lead story, side stories, and a three-column grid using CSS Grid.

## Files
- `index.html` contains the article and semantic page regions.
- `styles.css` defines the named-area CSS Grid and its narrow-screen layout.

## Try it
Open `index.html` in a browser and resize the window to see the columns collapse into a readable single-column flow.
