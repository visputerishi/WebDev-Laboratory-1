# P6: Full Portfolio Page Structure

## Aim
Organize a portfolio with semantic HTML sections for navigation, introduction, projects, and contact.

## Implementation
The completed portfolio is in [`index.html`](./index.html), styled by [`styles.css`](./styles.css). It uses a page header, labeled navigation, main content, sections with headings, project articles, and a footer.

## Try it
Open `index.html` in a browser and follow the navigation links to each section.
