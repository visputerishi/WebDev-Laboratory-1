# P7: Design Tokens and Typography

## Aim
Use CSS custom properties to establish reusable colors, spacing, surfaces, and a consistent type scale.

## Implementation
The completed example is [`index.html`](./index.html), with reusable color, spacing, and typography tokens in [`styles.css`](./styles.css). Edit the custom properties in `:root` to update the specimens consistently.

## Try it
Open `index.html` in a browser, then edit a CSS variable such as `--color-accent` and observe all the places that use it update together.
