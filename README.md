## Open and run the exercises

Open this repository folder in VS Code. For the portfolio, open `Module2/portfolio/index.html` in a browser. The independent P5 and P11 exercises can be opened from their folders in the same way. No dependencies or build tools are required.

The portfolio uses sample text such as “Your Name” and `hello@example.com`. Replace those placeholders with your own details before publishing.
